# Brand kit

Placeholder logos. Swap them for yours; nothing in the app depends on these exact files.

| File                | Use                                         |
| ------------------- | ------------------------------------------- |
| `logo-mark.svg`     | Square mark (favicon, social avatar).       |
| `logo-wordmark.svg` | Horizontal logo with the app name.          |

The app icon lives in `resources/icon.png` (1024×1024). Run
`npx tauri icon resources/icon.png` to generate the Windows `.ico`, macOS `.icns` and the other
platform sizes into `src-tauri/icons/`.
